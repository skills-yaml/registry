# skm 0.7.0

## skm

Agent Skill Manager (skm) - Manage agent skills via skills.yaml

Usage: skm <COMMAND>

Commands:
  version       Show the installed version and managed build identity
  init          Create or edit skills.yaml with sequential prompts, or create defaults for scripts
  install       Install and symlink all skills specified in skills.yaml
  add           Add a registry skill or published bundle to this project
  bundle        Add every skill in a published registry bundle to this project
  search        Search configured registries for skills and published bundles
  remove        Remove a skill from skills.yaml and unlink it from agent directories
  list          List all defined skills and verify their current linkage status
  check         Verify all skills match layout expectations and are correctly linked (useful for CI)
  update        Check for or install a verified SKM release update
  cache-update  Update local cache of skill registries
  setup         Run first-time setup (initialize base config and cache)
  init-config   Initialize global base configuration with default registry
  versions      List all available versions for a skill
  use           Switch a skill to a specific version
  update-skill  Update a skill to its latest version
  clean         Clean up SKM artifacts (broken symlinks, cache, etc.)
  config        Manage SKM configuration
  registry      Manage skill registries
  dev           Manage local development skills
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

## skm version

Options:
  -h, --help  Print help

## skm init

Create or edit skills.yaml with sequential prompts, or create defaults for scripts

Usage: skm init [OPTIONS]

Options:
      --name <NAME>
          Override the project name (new configurations default to the current folder name)
  -i, --interactive
          Open the interactive prompts (the default)
      --advanced
          Compatibility alias for the complete interactive prompt flow
  -g, --global
          Prepare for global installation; skills.yaml stays in the current directory
      --non-interactive
          Use non-interactive mode with default values
      --toolkit-manifest <TOOLKIT_MANIFEST>
          Select a repository-local Workspace toolkit manifest
      --toolkit-version <TOOLKIT_VERSION>
          Pin the selected toolkit version [default: 0.1.0]
      --bundle <BUNDLE>
          Select a toolkit bundle; repeat for multiple bundles
      --profile <PROFILE>
          Select an additional role profile; repeat for multiple profiles
      --workspace-standard <WORKSPACE_STANDARD>
          Pin a workspace standard, for example workspace-docs@5.0.0
      --workspace-source <WORKSPACE_SOURCE>
          Select a repository-local workspace standard source
      --workspace-revision <WORKSPACE_REVISION>
          Pin an immutable Git revision for a remote workspace source
      --workspace-integrity <WORKSPACE_INTEGRITY>
          Pin the expected SHA-256 package integrity for a remote workspace source
  -h, --help
          Print help

## skm install

Install and symlink all skills specified in skills.yaml

Usage: skm install [OPTIONS]

Options:
  -g, --global   Link skills globally (to user home directory) instead of project-local
      --dry-run  Preview the complete plan without writing
      --json     Emit the plan as JSON
  -y, --yes      Confirm non-interactive application
  -h, --help     Print help

## skm add

Add a registry skill or published bundle to this project

Usage: skm add [OPTIONS] <NAME>

Arguments:
  <NAME>  Skill or bundle ID (e.g. software-development/spec)

Options:
      --source <SOURCE>  Source registry name (defaults to 'default')
      --kind <KIND>      Select skill or bundle explicitly when an ID names both [possible values: skill, bundle]
      --path <PATH>      Path to a local skill directory (for local offline skills)
  -g, --global           Link skills globally instead of project-local
      --dry-run          Preview a bundle without writing
      --json             Emit a bundle plan as JSON without writing
      --yes              Apply a published bundle to this project
  -h, --help             Print help

## skm search

Usage: skm search [OPTIONS] <QUERY>

Arguments:
  <QUERY>  Skill or bundle ID, or part of one

Options:

  -h, --help                 Print help

## skm clean

  cache     Clean up registry cache

Options:
  -h, --help  Print help

## skm clean symlinks

Clean up broken and orphaned symlinks

Usage: skm clean symlinks [OPTIONS]

Options:
  -g, --global    Clean global symlinks
      --broken    Only clean broken symlinks
      --orphaned  Only clean orphaned symlinks
      --all       Clean all symlinks (broken + orphaned)
      --dry-run   Preview what would be removed
  -y, --yes       Skip confirmation
  -v, --verbose   Show verbose output
  -h, --help      Print help

## skm clean cache

Clean up registry cache

Usage: skm clean cache [OPTIONS] [REGISTRY]

Arguments:
  [REGISTRY]  Specific registry to clean

Options:
      --all           Clean all registry caches
      --old-versions  Remove old skill versions
  -k, --keep <KEEP>   Keep N most recent versions [default: 5]
      --dry-run       Preview what would be removed
  -y, --yes           Skip confirmation
      --stats         Show cache statistics
  -v, --verbose       Show verbose output
  -h, --help          Print help

## skm clean reset

Reset SKM to clean state

Usage: skm clean reset [OPTIONS]

Options:
      --config                   Reset configuration files
      --cache                    Clear all caches
      --symlinks                 Remove all symlinks
      --all                      Reset everything
      --backup                   Create backup before reset
      --backup-dir <BACKUP_DIR>  Directory to store backups
      --dry-run                  Preview what would be removed
  -y, --yes                      Skip confirmation
  -h, --help                     Print help
