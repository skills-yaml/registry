# Service Inventory

This file recorded the service inventory of a private host: internal
container names, the ports they listened on, and the public hostnames
routing to them. It was removed from this repository history on
2026-09-19.

The release that shipped it, system/devops-manager@1.0.0, is withdrawn.
See WITHDRAWN.yaml and docs/specs/done/redact-host-service-inventory.md
on the current main branch.
